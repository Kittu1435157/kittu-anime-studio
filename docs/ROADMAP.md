# Roadmap

## Stage 1 — Foundation
- [x] Monorepo, docs, API health endpoint, landing/workspace shell, initial database schema/RLS
- [ ] Supabase authentication integration
- [ ] Project CRUD
- [ ] Episode CRUD
- [ ] Character CRUD and secure reference uploads
- [ ] Automated RLS/security tests
- [ ] Production deployment

## Stage 2 — Character Studio
Character profiles, reference versioning, approved identity, private asset management.

## Stage 3 — Story Intelligence
Script intake, parsing, scene/shot breakdown, timings and dialogue extraction.

## Stage 4 — Storyboard Studio
Editable shot cards, camera instructions, prompts and approval.

## Stage 5 — Image Generation
Provider-neutral image adapters, keyframes and asset provenance.

## Stage 6 — Video Generation
ComfyUI/hosted adapters, durable queue, retries, progress and resume.

## Stage 7 — Voice and Audio
Dialogue, voice assignment, TTS, lip-sync, subtitles, music and effects.

## Stage 8 — Timeline and Rendering
Timeline editing, FFmpeg rendering, transitions and exports.

## Stage 9 — Public Platform
Creator profiles, sharing, moderation, quotas and abuse controls.

## Stage 10 — Production Intelligence
Continuity checks, motion control, batch rendering and model routing.
